# Sauzze TV PRO — updates

Updates for the Sauzze TV PRO app on Samsung televisions. The app fetches them by
itself at start-up; there is nothing to do here.

Sauzze TV PRO provides no content: it plays its user's own playlist.

*Mises à jour de l'application Sauzze TV PRO pour téléviseurs Samsung —
l'application les télécharge d'elle-même.*
