# Sauzze TV — updates

Updates for the Sauzze TV app on Samsung televisions. The app fetches them by
itself at start-up; there is nothing to do here.

Sauzze TV provides no content: it plays its user's own playlist.

*Mises à jour de l'application Sauzze TV pour téléviseurs Samsung —
l'application les télécharge d'elle-même.*
